# Hotel Revenue Leakage Analysis

## Project Overview

This project analyzes hotel booking data to identify potential revenue losses, understand booking and cancellation patterns, and discover opportunities to improve hotel revenue performance.

## Objectives

* Analyze hotel booking and revenue trends.
* Understand booking and cancellation patterns.
* Identify potential revenue leakage.
* Generate insights to support business decisions.

## Skills

Data Analysis | Data Cleaning | Exploratory Data Analysis (EDA) | Data Visualization | Business Insights

## Conclusion

This project demonstrates how data analytics can help understand hotel performance, identify potential revenue risks, and support data-driven business decisions.
